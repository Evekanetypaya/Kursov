# 🌸 Beautyness — База данных, Docker и Веб-сайт (Курсовая работа)

Полностью автономный проект для курсовой работы. Все файлы собраны в этой папке, чтобы проект можно было **скопировать на флешку или передать на любой другой компьютер (Windows / macOS / Linux)**, запустить в один клик и открыть в **DBeaver** и браузере.

---

## 🚀 Быстрый запуск на любом компьютере

### Шаг 1. Запуск Docker-контейнеров (База данных PostgreSQL + API)

Убедитесь, что на компьютере установлен и запущен **Docker Desktop**.

* **На Windows:**
  Просто дважды кликните по файлу **`start.bat`**  
  *(или откройте терминал в этой папке и выполните `docker compose up -d --build`)*

* **На macOS / Linux:**
  Откройте терминал в этой папке и запустите:
  ```bash
  ./start.sh
  ```

Контейнеры соберутся и запустятся автоматически. PostgreSQL сразу создаст базу данных `beautyness_db`, накатит таблицы и заполнит их стартовыми данными из файла `server/init.sql`.

---

## 🗄️ Подключение к базе через DBeaver

1. Откройте **DBeaver**.
2. Нажмите кнопку **«Новое соединение»** (иконка вилки с плюсом `+` в верхнем левом углу или меню `База данных` -> `Новое соединение...`).
3. В появившемся списке выберите **PostgreSQL** и нажмите **Далее (Next)**.
4. Заполните поля во вкладке **Главное (Main)**:

| Поле в DBeaver | Значение |
|---|---|
| **Хост (Host)** | `localhost` |
| **Порт (Port)** | `5432` |
| **База данных (Database)** | `beautyness_db` |
| **Пользователь (Username)** | `postgres` |
| **Пароль (Password)** | `postgres` |

5. Нажмите кнопку **«Тест соединения ...» (Test Connection)** внизу слева:
   * *Если DBeaver предложит скачать драйвер PostgreSQL — нажмите «Скачать» (Download), он загрузится за несколько секунд.*
   * Появится подтверждение `Connected` с зелёной галочкой.
6. Нажмите **Готово (Finish)**.

### Где смотреть таблицы в DBeaver:
В левой панели (Навигатор) раскройте дерево:
```text
beautyness_db
 └── Databases
      └── beautyness_db
           └── Schemas
                └── public
                     └── Tables
```

## 🌐 Запуск фронтенда (Сайт на React + Vite)

1. Откройте терминал в папке `vite-project`:
   ```bash
   cd vite-project
   npm install
   npm run dev
   ```
2. Откройте ссылку в браузере: `http://localhost:5173`

## 🎯 Как продемонстрировать преподавателю (Интерактив)

1. В **DBeaver** откройте таблицу `appointments` и перейдите во вкладку **Данные (Data)**.
2. На сайте перейдите в раздел записи (форма **Make an Appointment** на главной или странице Contact).
3. Введите свои имя, email, телефон и нажмите **MAKE AN APPOINTMENT**.
4. На сайте появится зеленое сообщение об успешной записи.
5. В **DBeaver** нажмите кнопку **Обновить (Refresh / F5)** — в таблице `appointments` мгновенно появится новая строка с введёнными данными!
